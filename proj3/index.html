System of Equations & Recovered Homography Matrix

Define the homography matrix H for homogeneous coordinates as:

$$ H = \begin{bmatrix} h_1 & h_2 & h_3 \\ h_4 & h_5 & h_6 \\ h_7 & h_8 & h_9 \end{bmatrix}, \quad h_9 = 1 $$

We have eight unknowns so need at least four points to be able to solve the system. Our 10 correspondances give us 20 equations – we have enough information!

Part A.3: Warp the Images

Example from Scene 1

The tradeoff between speed and quality for Nearest Neighbor (NN) and Bilinear (BIL) warping is: NN is significantly faster and produces similar quality images as the original; BIL is slower and produces a smoother image than the original.

Specifically, on this 2000 x 1500 image, NN warping took 26.13 seconds while BIL warping took 59.95 seconds. This time different is expected since for NN we are rounding to the nearest pixel value, thus we only examine 1 nearest neighbor. On the other hand, for BIL we examine 4 neighbors in order to perform a weighted average between them. Since more work is being done for BIL, the extra time is reasonable. Closely examining the below comparison images, we can see that the BIL version produces a smoother image, again due to the weighted averaging operation for every point, which filters some high frequencies. On the contrary, the NN doesn't perform any significant "softening" operation, so the result seems "sharper" or "noisier" as most high frequencies are kept.

Part A.4: Blend the Images into a Mosaic

Procedure Description

The main mosaic-creating function is create_mosaic(im1, im2, H), which intakes two images an a homography transformation matrix from im1 to im2. To create the mosaic, an important step is to generate weight maps for both input images, image 1 (im1) and image 2 (im2), using the create_weight_map function. This function assigns higher weights to the center of each image and gradually decreases the weights towards the edges, which helps reduce visible seams when blending. The weight map is calculated by measuring the Euclidean distance of each pixel from the center of the image and normalizing this distance by the maximum possible distance (from the center to a corner). This results in a map where the center has the highest weight (1) and the edges fall off to 0. Some examples shown below.

The homography matrix H is computed via the computeH function from previous parts, which aligns im1 with im2. This matrix is used to transform the corners of im1 into the coordinate system of im2. The corners of both images were represented in homogeneous coordinates and transformed accordingly. These transformed corners, along with the original corners of im2, were then used to calculate the bounding box of the mosaic. Specifically, the minimum and maximum x and y coordinates of all corners were found, and the mosaic dimensions were set based on these values, with additional padding added to prevent clipping. The function in charge of finding this new canvas size is compute_warped_bounds(im_shape, H).

To align both images within the mosaic, we have a translation matrix T, which shifts the entire mosaic into the positive coordinate space. The homography for im1 was then combined with this translation matrix to form the composite transformation matrix H_mosaic1, which was used to warp im1 into the mosaic coordinate system. For im2, only the translation matrix T was needed, and it was used to warp im2 into the same space. Both images were then warped using bilinear interpolation with the warpImageBilinear(im, H, output_shape) function, which maps each pixel from the original image to its new location in the mosaic.

To ensure proper blending, I also warped the weight maps for both images using the same transformations. This step ensures that the blending process takes into account the spatial alignment of both images and their respective weight maps!

Finally, to reduce edge artifacts, the warped images are blended together using weighted averaging, where the pixel values in the final mosaic were computed as a weighted sum of the corresponding pixels from im1 and im2, with the weights derived from the warped weight maps: $$\frac{im_1 \times w_1 + im_2 \times w_2}{w_T},\quad w_T = w_1 + w_2$$ See code for more details!
